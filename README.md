# Expense Tracker (Vite + React)

This project uses Vite for development and builds.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the development server. Open the printed local URL in your browser.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Previews the production build locally.

### `npm test`

Runs the test suite with Vitest.
